Group Hunter Pro 2.0 - نسخة بقاعدة بيانات جديدة

المحتويات:
- index.html: التطبيق
- manifest.webmanifest: إعدادات تثبيت التطبيق
- sw.js: التخزين المؤقت والعمل دون اتصال بعد الزيارة
- icon-192.png و icon-512.png: أيقونات التطبيق

التثبيت والتحديث:
1) فك ضغط الملف.
2) ارفع الملفات الستة إلى جذر مستودع GitHub Pages الحالي واستبدل الملفات التي لها الأسماء نفسها.
3) اضغط Commit changes وانتظر اكتمال Pages deployment.
4) افتح رابط المشروع ثم حدّث الصفحة. إذا ظهر إصدار قديم، أغلق التطبيق/علامة التبويب وافتح الرابط في نافذة خاصة أو امسح بيانات الموقع من إعدادات المتصفح.
5) يمكن تثبيت التطبيق من قائمة Chrome > Add to Home screen / Install app.

ملاحظات:
- هذه النسخة تبدأ بقاعدة بيانات مستقلة وفارغة ولا تستورد بيانات الإصدار السابق تلقائياً.
- تدعم حفظ حتى 1000 مجموعة يدوياً، والتصنيف حسب الدور والصلاحيات، ومخطط منشورات ومتابعة الحملات والنسخ الاحتياطي.
- لا تجمع بيانات Facebook ولا تنشر تلقائياً في المجموعات. مخطط النشر يجهز النص ويفتح رابط المجموعة للمراجعة والنشر اليدوي، لأن النشر الآلي الجماعي غير مدعوم هنا.
- البيانات محفوظة محلياً في المتصفح. استخدم Backup بانتظام.
