Group Hunter Pro 2.0 – Android PWA (with data migration)

الميزات:
- قاعدة بيانات حتى 1000 مجموعة.
- حفظ الدور والصلاحيات وقواعد المجموعة ومؤشرات النشاط المرئية.
- إعداد مسودات تسويق مع الإفصاح عن رابط العمولة.
- مخطط منشورات للمجموعات التي تديرها، مع نسخ النص وفتح المجموعة للنشر اليدوي.
- تتبع النقرات والطلبات والعمولات.
- تصدير CSV ونسخ احتياطي JSON واستعادة النسخة.

الحفاظ على البيانات:
- الإصدار 2.0 يقرأ تلقائياً بيانات الإصدار السابق من المفتاح المحلي ghp-pwa-v1 عند فتحه على نفس النطاق ونفس المتصفح/ملف Chrome.
- لا يحذف مفتاح الإصدار القديم؛ ويُبقيه كنسخة احتياطية محلية.
- قبل التحديث، افتح التطبيق الحالي > Backup > Download JSON backup واحفظ الملف على الهاتف.
- إذا فتحت التطبيق من متصفح أو ملف تعريف مختلف، فلن تكون بيانات التخزين المحلي القديم متاحة تلقائياً؛ استخدم Restore JSON backup.

التحديث عبر GitHub Pages:
1. فك ضغط هذا الملف.
2. في مستودع GitHub الحالي group-hunter-pro اختر Add file > Upload files.
3. ارفع الملفات الستة إلى جذر المستودع واستبدل الملفات المتطابقة.
4. Commit changes وانتظر نجاح Pages deployment.
5. افتح رابط الموقع في Chrome ثم حدّثه. إذا بقي الإصدار القديم، أغلق التطبيق وافتحه مجدداً بعد اتصال الإنترنت.

تنبيه بشأن Facebook:
هذه الأداة لا تجمع بيانات Facebook ولا تسجل الدخول نيابة عنك ولا تنشر تلقائياً على مئات المجموعات. مخطط النشر ينظم المحتوى للمجموعات التي تملكها/تديرها ويتيح فتح المجموعة ونسخ النص لتراجعه وتنشره يدوياً وفق قواعد المجموعة وأدوات Meta الرسمية. لا توجد طريقة مضمونة لتجاوز قيود المنصة.
