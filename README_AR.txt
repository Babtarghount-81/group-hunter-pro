Group Hunter Pro PWA — Chrome Android

مهم: لا يمكن تثبيت PWA من ملف ZIP مباشرة. يجب رفع محتويات هذا المجلد إلى استضافة HTTPS (مثل GitHub Pages أو Netlify أو استضافة موقعك). بعد ذلك افتح رابط الموقع في Chrome Android.

التثبيت:
1) افتح رابط HTTPS في Chrome.
2) انتظر تحميل الصفحة.
3) افتح قائمة Chrome ⋮.
4) اختر Install app أو Add to Home screen.
5) وافق على التثبيت. قد تختلف التسمية حسب إصدار Chrome.

المحتويات:
- بحث Facebook Groups بفتح صفحة البحث فقط.
- إدخال وحفظ بيانات المجموعات المرئية يدوياً.
- تقييم نشاط بحثي وليس عدداً حقيقياً للمستخدمين النشطين.
- مولد منشورات أفلييت مع إفصاح.
- تتبع النقرات والطلبات والعمولات.
- تصدير CSV ونسخ احتياطي JSON.
- عمل دون اتصال بعد أول زيارة عبر Service Worker.

حدود: لا يوجد كشط آلي لبيانات Facebook، أو الوصول إلى بيانات خاصة، أو نشر آلي. لا تستخدمه لتجاوز القيود أو قواعد المجموعات.
